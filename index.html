  1. 先测量，再决定。音高、时长、频段、像素、行数——凡是能测的都先测，别靠听感和眼感拍参数。

02换声与音频RVC 换声、后处理、发送1936 字

适用

有人丢来一段 wav/mp3 说"换成我的音色""改成 44 秒""命名《XX》发出去"。

工具链（本机固定路径）

件位置
转换脚本E:\工作区\voice-data\rvc_convert.py（用法：<in> <out> [pitch] [f0_method] [index] [index_rate]）
PythonE:\工作区\qq-bridge\sing\venv\Scripts\python.exe（3.12 / torch cu128 / torch.cuda.is_available()=True）
模型E:\rvcm\linxiaoman.pth + E:\rvcm\linxiaoman.index（index_rate 0.65）
探测工作区 probe_song.py（sr/ch/dur/rms/peak/四段频带/centroid/rmvpe 统计）
后处理工作区 post.py <in> <out> [shelf_db]（40k→44.1k + 5k 高架 + 裁静音 + 归一 -1 dBFS）
裁剪工作区 trim.py <in> <out> <秒>（截断 + 150ms 淡出 + 峰值归一）

标准流程（六步）

  1. 先设环境变量（不设必假死，见坑 1）：TEMP/TMP → 工作区 tmp，NUMBA_CACHE_DIR → 工作区 numba_cache。
  2. 探测：probe_song.py 拿 sr/时长/rms/peak/频段/rmvpe 中位与 p10-p90。
  3. 定 pitch：看 rmvpe 中位是否落在目标音色舒适区（林小满 A3–E5 ≈ 220–660 Hz）。在区内就 pitch 0，别顺手升八度。
  4. 转换：rvc_convert.py <src> <out> 0 rmvpe E:\rvcm\linxiaoman.index 0.65。60 秒内出片（3–5 秒）属正常。
  5. 后处理：post.py 补高频（+2.0~3.5 dB @5 kHz 视源而定）、裁首尾静音、峰值归一到 -1 dBFS。
  6. 复测：再跑 rmvpe 与频段，确认成品中位与源差 < 1 Hz（没移调）、峰值 0.89 左右、>4k 能量有提升。

判据（数字说话）

  • f0 中位与源差 < 1 Hz → 没有意外移调；p10–p90 跨度不应变宽。
  • 峰值 0.89（−1 dBFS）→ 不削波。
  • >4k 能量占比提升 0.5–1.5 个百分点属正常；>8k 若 0.0% 说明太闷，把高架加到 3.5 dB。
  • 人声收尾时刻要报给用户：trim 切在长音中间时，先说"切点落在 26.0 秒的长音里"，别等对方听出来。

坑（都踩过）

  1. 沙箱里 librosa 假死：numba 走 tempfile.NamedTemporaryFile，默认 TEMP 被沙箱挡住 → import librosa.core.pitch 无限阻塞（进程活着、CPU 慢涨、零输出）。设 TEMP/TMP/NUMBA_CACHE_DIR 后同一段音频 4.77 秒出片。
  2. 测音高别用自相关：会把 295 Hz 报成 169 Hz（差一个八度），据此升八度就整首飘了。用 rvc_cli\rvc\lib\predictors\RMVPE.py 的 RMVPE0Predictor(model_path, is_half, device).infer_from_audio(16k float32, thred=0.03)。
  3. rvc_cli\rvc\configs\v1\40000.json 带 BOM 会报 Failed to parse JSON，不影响 40k v2 模型；pydub 报找不到 ffmpeg 也无影响。
  4. 中文不能走命令行参数：Windows shell 按 GBK 转码，文件名/参数到 python 变乱码。要传中文就写进 .py 里硬编码，或写 UTF-8 文件再读。
  5. | tail -25 会缓冲住 stdout，长任务看起来像卡死 → 长任务用后台 job，别管道截尾。

发歌闸门（教训换来的硬规矩）

发歌那几秒如果 QQ 那头她也在回话，读起来像"边聊天边塞歌"。所以：先读 state\social-v2.json 最后一条消息，距今 ≥120 秒才发；等不到就放弃，不硬塞。

静默与唤醒的两条硬限制

  1. 触发器不能全清：无限期潜水必须至少保留一个唤醒条件→ 静默版只留 poke:true。
  2. 还在聊天时设不了静默：需"连续 5 分钟无新消息"（preSleepWaitMs=300000，每条新消息重置）→ 用 hush.py 轮询，或先把状态查清再动手。

语音库管理

  • 发之前先 list_voices.py 对一遍名字；改名可以，别硬删：把旧件 Move-Item 到库外 voice-trash-<日期>，库里剩下的会自动消失。
  • 增删后要同步人格卡 E:\工作区\qq-bridge\roles\林小满.md 的「我自己的歌」一节（人格提示词每条消息前注入，热生效，不用重启）。

坑

  • config.json 若被写成带 BOM，脚本报 Unexpected UTF-8 BOM → 读文件统一 encoding="utf-8-sig"。
  • recentMessages 每会话只留最近 100 条，热闹的一天下午就刷没了 → 当天要复述就在当天做。
  • 中文输出乱码是控制台编码，不是文件坏了：PYTHONIOENCODING=utf-8。

prompt 写法（四件事写全，不然任务会跑偏）

  1. 先查重：写清"读某个文件末尾，若今天已有条目就跳过并回一句"，避免重复写同一个人/同一件事。
  2. 输入从哪来：给出确切路径与命令（如 qqday.py <key>、social-v2.json 的 recentMessages），不要让执行者自己找。
  3. 落到哪、怎么落：目标文件绝对路径 + "必须用 edit 工具 + danger-full-access，shell 写桌面会被拒"。
  4. 汇报要多短：一句"写了谁、标题"，不贴全文。

无头截图验证（唯一靠谱的"眼睛"）

& $edge --headless=new --user-data-dir="$dir\_prof" --no-first-run --disable-extensions `
  --hide-scrollbars --force-device-scale-factor=1 --virtual-time-budget=5000 `
  --window-size=1440,3600 --screenshot="$dir\shot.png" "file:///<路径>"
  • 必须直接调：用 python subprocess 起 msedge 会 TimeoutExpired（挂死）；且要 danger-full-access，否则 CreateFile 拒绝访问、图不生成。
  • 截图文件在 pwsh 返回之后才落盘，紧接着 Get-Item 可能"找不到"→ 等 1–2 秒再查。
  • 时间轴截图用 --virtual-time-budget=<ms> 卡点；--window-size 有最小宽度，测手机用 492。

Canvas / WebGL 场景要点

  • 静态层预渲染到离屏 canvas，每帧只 drawImage 一次 + 画动的东西；DPR 上限 1.6–2。
  • 超出视口就停 rAF（IntersectionObserver），prefers-reduced-motion 下只画一帧。
  • WebGL 兜底必须有：getContext 为空、编译失败、webglcontextlost 三种都要回落到 2D 版本。
  • 动画量级：水光 100–150 个、鹤 3 只，足够；再多是浪费。

调试手法

  • 独立编译页：把着色器源码抠出来单独编译，把 compiled / infoLog / link 写进页面再用 Edge 截图 —— 一眼看到 GLSL 报错原文（比如 'skyCol' : no matching overloaded function found，原因是函数定义在调用之后）。
  • 状态探针：注入一段脚本，把 DOM 取得的关键尺寸/类名/opacity 打成大字截图，比猜快得多。

坑

  • 类名撞车：给山格加 .pc，结果同名 .pname .pc（序号）继承了 flex:1 1 0，序号被拉满一行。改名前先 grep 一遍类名。
  • min-height:100vh + 超长窗口做整页截图会让首屏吃掉整页高度 → 截图前把首屏钉成固定像素。
  • 布局要"山错落、字齐平"：拆成两行（山行 + 清单行），两行用同一组 flex-grow 与 gap，列宽才会严丝合缝对齐。
  • 注释别随手批量删：清 /* */ 时要按 /* 到 */ 配对删，纯文本里出现 : 不算注释（曾把 selector 中间的冒号当注释删掉，整页空白）。

2026-11-01 · 站点大翻新（动效 / 昼夜 / 光标）

这一轮把 Y-STUDIO 从「静态纸面」做成了「有反应的纸面」。下面是可复用的做法与当天踩的坑，按能不能直接照做排序。

一、昼夜主题：先把颜色变成通道

只改 --paper 是没用的——全站有几十处 rgba(239,237,228,α) 这类字面量，会留下一片白斑。正确顺序：

  1. 在 :root 加 --paper-rgb: 239,237,228; --ink-rgb: 22,36,31;
  2. 把字面量批量换成 rgba(var(--paper-rgb), α) / rgba(var(--ink-rgb), α)（part1 改 15 处、part2 改 35 处）
  3. 再写 html[data-time="night"]{ … } 覆盖 16 个变量 + 12 条专项规则（遮罩、灯箱、图版、输入框、三维画布滤镜）

坑：夜间那段 CSS 如果追加到 part2.css.html 末尾，等于写在 </style> 之外，浏览器直接当文本丢掉——表现是 data-time="night" 挂上了、--paper 却没变。追加样式的铁律：先 rfind("</style>") 再插，插完用探针读 getComputedStyle 验证。

二、天空着色器做多相位

uniform vec3 u_tod;（x=夜、y=暮、z=晨），在调色前按权重混合：

  • 暮：col*vec3(1.10,0.93,0.84) + vec3(.070,.026,.004)*band（暖 + 天顶偏紫）
  • 晨：天顶 +vec3(.055,.075,.090)*hi、地平线淡粉、整体混 38% 去饱和
  • 夜：col*vec3(.24,.30,.42) 再混 vec3(.075,.105,.155)，外加星（正弦闪烁）、月（两层 smoothstep：圆盘 + 光晕）、水面月影

分档用小时：<5 夜、5–6.5 夜→晨、6.5–8 晨、8–16 昼、16–18 昼→暮、18–20 暮→夜。每 60 秒 + visibilitychange 重算，?time=night 可强制并写进 localStorage。

遇到"做张海报/插画"，先确认这三类里有没有可用的；都没有就直说并用下面的代码方案顶上。

代码画插画的可用手法

  1. 超采样：3–4 倍画布再 LANCZOS 缩回，边缘才不毛。
  2. 手绘感：每个形状的路径点加 1–2px 随机抖动；同一条轮廓叠 2 遍（第二遍低透明度、轻微偏移）；圆/椭圆半径加 sin(3θ) 起伏。
  3. 纸纹：以 255 为基准做 ±6 的噪声再 multiply；千万别用 128 基准（会把整幅压成灰）。
  4. 干笔缺口：alpha 乘 (0.55 + 0.75*噪声) 再阈值化，边缘就有毛刺。
  5. 四色收敛：先 quantize(colors=4, MEDIANCUT, dither=NONE) 再中值滤波，得到色板；但直接拿来做"纸剪"会糊成一团（实测失败），只适合取色。

海报版式（3:4 竖版 · 编辑风）

  • 画布 1500×2000；上下各 1000px，中间一条 1–2px 米灰细线。
  • 上半 = 原图（cover 裁切，别拉伸），只做轻分级：饱和 ×0.93、红 ×1.014、蓝 ×0.986、整体 ×1.02。
  • 下半 = 暖白纸面（#FAF6ED），插画边长 ≈ 画布宽 ×0.30（占下半 11–12%，符合"10–20%"）。
  • 文字：极小号（21px 标题 / 16px 副题），贴左下 96px 内边距，颜色 #48403 6 与 #80766 6 这一类低对比墨色；宁可不写，也别写长句。
  • 交付：同时给"带字"和"无字"两版，让人挑。

坑

  • 海报下半那种"纸剪分色"做法（原图 → 四色 → 位移抖动）会丢掉可辨识的形状，只剩色块；插画要么手画路径，要么等真模型。
  • 原图若是游戏/软件截图，右上角常有 FPS/GPU 之类 HUD，属于界面不属于画面，裁掉并告知。
